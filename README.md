## 已验证到什么程度

截至 2026-10-12，最新结论来自[各 100 次有效样本验证](docs/sdk-1.1.0-samples.md)。结果是指定配置的观测，不是设备实时状态。

| 项目 | 最新结果与边界 |
| --- | --- |
| 独立语言生成 | 平均 85.740 token/s，原厂 89.95 token/s，低约 4.68% |
| 独立语言 TTFT | 平均 119.993 ms，原厂 106.92 ms，高约 12.23% |
| 视觉阶段 | 平均 114.052 ms，含输入同步、模型运行、输出同步；不含完整图片业务链路 |
| 重复性 | 语言 110 次、视觉 101 次完成，各剔除预热后统计 100 次；11 个进程均正常退出 |
| 对齐限制 | 本机 M.2 850MHz，原厂 1GHz；原厂模型哈希、完整上下文及视觉计时边界未全部披露 |
| 待验证 | 1.1.0 图片复核吞吐、并发、高负载长稳和标注准确率 |

原厂对比入口见[原生性能对照](docs/native-comparison.md)。旧版约 **1.14 张/秒**属于 1.0.4 短提示词、20 图轮换、单并发业务基线，不能由新版 token/s 推算升级后的图片吞吐。旧版并发失败和提前结束记录保留在[历史报告](docs/README.md#历史记录)。

## 快速启动

网页控制服务需要 Node.js 22 或更新版本，无第三方 Node.js 运行依赖。VLM 模型服务须另外部署；现有模型启动脚本使用旧 Firefly 包的文件名，不能直接套用官方 1.1.0 包，见[版本与部署说明](docs/deployment.md)。

```bash
git clone git@github.com:XingTunAI/rk1828-vlm-demo.git
cd rk1828-vlm-demo
node server.js
```

打开 `http://127.0.0.1:8787`，填写从控制服务所在机器可访问的模型地址（以 `/v1` 结尾），点击连接，勾选图集或上传图片，再进行问答或测试。每批最多 20 张，每张 4 MiB，总计 20 MiB；问答使用第一张，测试逐张轮换。

控制服务默认只监听本机，端口可由 `PORT` 修改。PC 转发和板端运行的区别见 [模型部署](docs/qwen3-vl-board.md)。

## 功能与限制

- 支持单图多轮问答，以及单请求、并发、定速、突发和持续负载测试；HTTP 并发不代表硬件并行能力。
- 板端脚本采集 NPU 利用率、温度、设备与主机内存，保存请求和采样记录；网页尚未展示实时设备资源曲线。
- 单次请求仅含一张图；视频、摄像头、自动准确率评分和自动故障恢复尚未实现。
- 素材灰度 JPEG 使用可追溯 RGB 副本；许可和原图来源见 [素材库](materials/README.md)。
- 报告保存在 `results/`，默认不提交 Git。逐请求报告不保存图片本体、密钥或回答；报告中的提示词与服务地址需在对外分享前检查。
- SDK 文档副本和模型权重不随仓库发布。后续边界验证见 [测试计划](docs/memory-stress.md)。

## 开发

```bash
node --test
node scripts/verify-materials.mjs
```

`server.js` 为控制服务，`lib/` 为推理与调度逻辑，`public/` 为界面，`scripts/` 为板端运行和素材工具，`docs/` 为使用说明与实测报告。
