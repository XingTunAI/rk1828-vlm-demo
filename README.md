## 快速启动

网页控制服务需要 Node.js 22 或更新版本，无第三方 Node.js 运行依赖。VLM 模型服务须另外部署。

```bash
git clone git@github.com:XingTunAI/rk1828-vlm-demo.git
cd rk1828-vlm-demo
node server.js
```

打开 `http://127.0.0.1:8787`，填写从控制服务所在机器可访问的模型地址（以 `/v1` 结尾），点击连接，勾选图集或上传图片，再进行问答或测试。每批最多 20 张，每张 4 MiB，总计 20 MiB；问答使用第一张，测试逐张轮换。

控制服务默认只监听本机，端口可由 `PORT` 修改。PC 转发和板端运行的区别见 [模型部署](docs/qwen3-vl-board.md)。

## 功能与限制

- 支持单图多轮问答，以及单请求、并发、定速、突发和持续负载测试；HTTP 并发不代表硬件并行能力。
- 板端脚本采集 NPU 利用率、温度、设备与主机内存，保存请求和采样记录；网页尚未展示实时设备资源曲线。
- 单次请求仅含一张图；视频、摄像头、自动准确率评分和自动故障恢复尚未实现。
- 素材灰度 JPEG 使用可追溯 RGB 副本；许可和原图来源见 [素材库](materials/README.md)。
- 报告保存在 `results/`，默认不提交 Git。逐请求报告不保存图片本体、密钥或回答；报告中的提示词与服务地址需在对外分享前检查。
- SDK 文档副本和模型权重不随仓库发布。后续边界验证见 [测试计划](docs/memory-stress.md)。

## 开发

```bash
node --test
node scripts/verify-materials.mjs
```

`server.js` 为控制服务，`lib/` 为推理与调度逻辑，`public/` 为界面，`scripts/` 为板端运行和素材工具，`docs/` 为使用说明与实测报告。
