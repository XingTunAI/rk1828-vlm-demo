Git 保存说明、模型校验清单及精选实测数据。SDK 安装包和厂商 PDF 保留在本地 `official/local/`；完整模型权重未包含在 Git 中，按模型说明获取。原有 `results/` 本地原始记录保持不变。

最新长测：原厂 `rknn3_vlm_demo -tl 12` 完成 **21,793 轮**，退出码 0，SDK 错误标记及采样失败均为 0。NPU 样本均值 **90.93%**、峰值 **91%**，最高温度 **58℃**，设备内存峰值 **2757 MB**、结束后 **36 MB**。这是固定图原生老化，不代表最大并发或业务准确率；末次生成速度 85.039 token/s 不与上表均值混用。
