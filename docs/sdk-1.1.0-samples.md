# SDK 1.1.0 扩样重复性验证

[文档导航](README.md)

2026-10-12。延续官方Qwen3-VL-4B、Runtime/固件1.1.0、RK3588 performance、M.2 850MHz、全核0xff、上下文1024。原厂基准来源及对齐限制见[首轮报告](sdk-1.1.0-retest.md)。

## 方法与样本

语言：10个独立进程，每组11次。官方eval-perf源码仅将test_num从3改为11；编译-O3 -DNDEBUG。每组剔除Run0，100次有效样本；输入128、输出128，Generate阶段127token。总计110次语言推理正常完成。

视觉：新版自带rknn3_model_test执行101次，剔除第一次，100次有效样本。使用同一官方demo.jpg，经Pillow转RGB、resize至384×384、保存UINT8 NHWC NPY；不含图片解码或resize耗时。逐次统计输入同步、模型run和输出同步，启用输出checksum一致性检查。所有101次正常完成，未报告checksum不一致。固定图像重复，不是100张不同图片，预处理也不等同于原生VLM的RGA路径。

| 指标 | 样本数 | 均值 | 中位数 | P95 | 最小 | 最大 |

| Vision总耗时 ms | 100 | 114.052 | 114.016 | 114.461 | 113.387 | 115.327 |
| Vision模型run ms | 100 | 98.962 | 98.966 | 99.039 | 98.809 | 99.103 |

| 输出同步 ms | 100 | 13.145 | 13.106 | 13.568 | 12.717 | 14.250 |

P95采用排序后线性插值；吞吐的P95是高端速度，不表示慢尾，慢速表现应看最小吞吐或TPOT高分位。样本来自同一设备和固定输入，不能视为跨设备独立验证。

## 原厂对比

- Decode token/s：本机85.740，原厂89.95，相对差异-4.68%。
- TTFT ms：本机119.993，原厂106.92，相对差异+12.23%。
- Vision总耗时 ms：本机114.052，原厂108.23，相对差异+5.38%。

原厂NPU为1GHz，本机为M.2上限850MHz；原厂未提供模型哈希、完整上下文及视觉全部计时边界，不宣称完全同条件。

## 状态与限制

全流程约413.9秒，含10次独立语言模型加载、视觉加载及监控查询。11个测试进程退出码均为0。语言110次、视觉101次完成；有效统计各100次。CPU governor通过finally恢复原schedutil。

每组结束后查询设备状态和NPU频率，没有连续遥测；组间温度观察范围为43–45℃，不是运行中最高温度。不能据组间快照判断持续满载或峰值内存。本轮验证重复性，不代表长稳、并发能力、业务准确率、视频FPS或完整图片吞吐。
