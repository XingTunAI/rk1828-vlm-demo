# RK1828 官方模型与 SDK 1.1.0 复测报告

日期：2026-10-12。范围：原生语言性能、视觉阶段及单图图文功能短测。

## 结论

有效语言生成吞吐均值 **85.785 token/s**，为原厂89.95的95.37%；首token均值 **119.46 ms**，比原厂106.92高11.73%。视觉工具末次计时115ms，比原厂108.23高6.25%。未出现此前MODEL_SETUP初始化失败。

这不是完全同条件硬件测试：本机M.2最高850MHz，原厂1GHz；原厂未公开模型哈希、完整上下文和PCIe宽度。不能推算本机1GHz成绩，也不能把差异全部归因于频率。

## 来源与配置

原厂基准：SDK `00_RKNN3_SDK_Release_Notes_V1.1.0.pdf` 第12页性能表、第13页条件；测试方法见官方rknn3-model-zoo的tools/rknn3_llm_test/README.md。原厂说明视觉和语言独立测试、LLM输入128/输出128、RK3588 performance、PCIe、NPU1GHz。

## 限制与历史结果

本次为少量原生短测，不提供可靠P95/P99、长期稳定性、并发能力、业务图片吞吐、视频FPS或准确率结论。固定单图不代表20图轮换或YOLO框内事件复核。

此前约39.71token/s使用Firefly转换包、上下文32768和1.0.4软件栈；当前模型和软件栈同时改变，不能将约2.16倍提升归因于某一个因素。旧配置的1.14张/秒和119ms视觉结果不拼接到新版成绩。
