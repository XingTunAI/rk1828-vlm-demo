## 文档维护约定

- 首页保留当前摘要，本页维护全部文档入口；操作方法与测试报告分开。
- 每份报告注明日期、模型来源、Runtime / 固件、频率、输入输出、预热、样本量、时长及计时边界。
- 失败、取消、人工停止和成功分别记录；新报告不覆盖旧数据，不混用跨版本成绩。
- 原始 JSON / JSONL、逐次 CSV、模型权重和 SDK 文档副本仅在本地保存，`results/` 不上传 GitHub。
- 请求成功率不等于准确率；NPU 采样峰值不等于持续满载；内存占用不等于计算利用率。
